
# FlexiPlan
### Optimizador de secuencias flexográficas

**Versión 1.0.1 | Windows y macOS**

FlexiPlan es una aplicación de escritorio desarrollada para optimizar la programación y secuenciación de pedidos en procesos de impresión flexográfica, buscando reducir los tiempos de preparación y el desperdicio de materiales, papel y solventes.

## Descargar

[![Descargar FlexiPlan](https://img.shields.io/badge/Descargar-FlexiPlan%20v1.0.1-blue?style=for-the-badge)](https://github.com/juandmorenop-art/FlexiPlan-Descargas/releases/tag/v1.0.1)


## Características

- Secuenciación y programación de pedidos.
- Optimización de cambios de papel y solvente.
- Modelo de Programación Entera Binaria (PEB).
- Análisis mediante teoría de colas.
- Importación de archivos Excel y CSV.
- Exportación de resultados.
